Amazon Style E-Commerce Front-End Replica

A responsive, high-performance web application recreating the core shopping experience of an Amazon product interface. Built from scratch using modern web development fundamentals, incorporating dynamic DOM manipulation, real-time cart state management, and complex filtering algorithms.

🚀 Key Features

Dynamic Shopping Cart System:

Real-time item additions and removals.

Instant quantity adjustments with recalculations of totals.

Interactive slide-out cart menu.

Advanced Product Filtering:

Multi-category filtering (Mobiles, Home, Fashion).

Custom min-to-max price boundary range filtering.

Sorting Capabilities:

Dynamic sorting by price (Low to High, High to Low) and featured items.

UI/UX Engineering:

Replicates production-grade Amazon UI elements.

Clean layout designed with accessibility and clarity in mind.

🛠️ Tech Stack & Tools

Frontend: HTML5, CSS3, Modern JavaScript (ES6+)

Development Tools: Visual Studio Code, Git, GitHub

AI Assistance: Blackbox AI (used for workflow acceleration, debugging, and code optimization)

📁 Repository Structure

.
├── index.html     # Main HTML structure

├── style.css      # Styling, layout design, and responsive design rules

└── js.js          # JavaScript logic for DOM elements, state, cart, & filters
